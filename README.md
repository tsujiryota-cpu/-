# 🧠 クソどうでもいい性格診断【MBTI風】

MBTIっぽいけど1ミリも科学的根拠がない、友達との身内ネタ用16タイプ診断です。

## 遊び方

`index.html` をブラウザで開くだけ。スマホでもPCでも動きます。
サーバー不要・依存ライブラリなしの1ファイル完結。

GitHub Pages を有効にすれば URL を友達に送るだけで遊べます
(リポジトリの Settings → Pages → Branch を選んで Save)。

## 診断の仕組み

MBTIのパロディで、4つの軸 × 各3問 = 全12問に答えると16タイプのどれかに分類されます。

| 軸 | 前者 | 後者 |
|---|---|---|
| テンション | **P** パリピ | **O** お通夜 |
| 思考回路 | **N** 脳筋 | **R** 屁理屈 |
| 金銭感覚 | **S** 散財 | **K** ケチ |
| 時間感覚 | **C** 遅刻魔 | **J** 時間の奴隷 |

例:`PNSC` =「歩く治外法権」、`ORKJ` =「人間Excel」など。

## 🎯 身内ネタにカスタマイズする方法

`index.html` の `<script>` 冒頭にある **「★ 身内ネタカスタマイズゾーン ★」** を書き換えるだけです。

### 質問を変える

```js
{ axis: 0, text: "○○(友達の名前)がまたアレをやらかした。あなたは?", choices: [
  ["一緒にやらかす", 1],       // +1 = 前者(パリピ等)寄り
  ["写真だけ撮る", 0],          //  0 = どっちつかず
  ["先に帰る", -1],             // -1 = 後者(お通夜等)寄り
]},
```

- `axis` は 0〜3(上の表の順)
- 各軸の質問数は自由に増減OK(バーの%計算は「1軸3問」前提なので、変えるなら `showResult` 内の `+ 3) / 6` をその軸の質問数に合わせて調整)

### 診断結果を変える

```js
PNSC: { name: "歩く治外法権",           // タイプ名 → 身内のあだ名にすると最高
  tagline: "ルール?聞いたことないですね",  // 一言キャッチコピー
  desc: "どんな人かの説明",
  manual: "取扱説明書(この人との付き合い方)",
  best: "ORKJ",   // 相性◎のタイプコード
  worst: "PRKJ" }, // 相性✕のタイプコード
```

軸のラベル(パリピ/お通夜 など)は `AXES` を書き換えれば変更できます。
