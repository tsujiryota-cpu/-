# 経費精算シートの追記

レシート写真から明細を読み取り、既存の `経費精算.xlsx`（Googleドライブ・マイドライブ直下、
fileId `1jnln7p-3b4yS_TbJayp1bA0hxYDg9Ouj`）に **写真1枚につきシート1枚** を追記する。

既存シート（`出納帳_写真1`〜`出納帳_写真3`）と同じレイアウト・同じ書式で揃えること。
書式の再現は `add_sheet.py` が担当するので、**手作業で openpyxl を使ってブックを保存しないこと**
（ブックには埋め込み画像とセルコメントがあり、openpyxl で保存すると画像が失われる）。

## シートの形

| | A | B | C | D | E |
|---|---|---|---|---|---|
| 1 | `出納帳（写真N：2026年8月1日〜8月2日）` A1:E1結合・太字14pt・中央 | | | | |
| 2 | 日付 | 支払先 | 内容 | 支払方法 | 金額（円） |
| 3〜 | 日付 | 店名・支払先 | 品目・内容 | 現金/クレジット/QUICPay等 | 金額 |
| 末 | | | | 合計 | `=SUM(E3:E<末-1>)` |

シート名は `出納帳_写真N`（N は既存シートの続き番号、`add_sheet.py` が自動採番）。

## 手順

### 1. 写真から明細を読み取る

写真ごとに、レシート1枚＝明細1行として次を読み取る。

- **日付** — レシートの発行日。年が印字されていなければ、他のレシートや文脈から補う。
- **支払先** — 店名・事業者名。支店名まで入れる（例: `ツルハドラッグ 宮前店`）。
- **内容** — 何を買ったか。既存シートの書き方に合わせて括弧で補足を入れる。
  - ガソリン: `ガソリン（レギュラー 22.25L @159.0）`
  - 駐車料金: `駐車料金（3時間14分）` / `駐車料金（12:33〜12:56）`
  - 点数が多い買い物: `食料品・パン等（27点）`
  - 食券番号やレシート番号があれば `（食券 #1153）`
- **支払方法** — レシート下部の支払欄をそのまま（`現金` / `クレジット` / `クレジット（JCB）` /
  `QUICPay` / `楽天ペイ` / `現金（券売機）` など）。
- **金額** — 税込の支払合計（値引後）。値引があれば内容に `（値引▲40円含む）` と補足する。

読み取れない箇所は推測で埋めず、`テンポソン（判読推定）` のように `（判読推定）` を付けて
残す（既存シートと同じ扱い）。合計金額がレシート合計と合わないときは、
勝手に調整せずユーザーに確認する。

### 2. 明細を JSON にする（写真1枚につき1ファイル）

```json
{
  "rows": [
    {"date": "2026-08-12", "payee": "アポロステーション セルフ大町SS",
     "description": "ガソリン（レギュラー 20.00L @159.0）",
     "method": "クレジット", "amount": 3180}
  ]
}
```

- `title` / `sheet_name` は省略でよい（日付範囲と連番から自動生成される）。
- 日付は `2026-08-12` / `2026/08/12` / `2026年8月12日` のいずれでもよい。
- 金額は `3180` でも `"3,180"` でもよい。
- 行の並びは日付順に自動で整列される。

### 3. 最新の経費精算.xlsx を取得する

`mcp__Google_Drive__download_file_content` に fileId を渡す。結果は base64 で、
大きいためツール結果ファイルに保存される。そこから復元する:

```bash
jq -r '.content' <ツール結果ファイル> | base64 -d > 経費精算.xlsx
```

必ず毎回ドライブから取り直す（ローカルの古いコピーに追記すると、他の更新を巻き戻す）。

### 4. シートを追記する

写真が複数枚あるときは、JSON ごとに順番に実行する（1回=1シート）。

```bash
python3 .claude/skills/keihi-seisan/add_sheet.py \
  --workbook 経費精算.xlsx --rows rows1.json   # 上書き実行でシートが積み上がる
python3 .claude/skills/keihi-seisan/add_sheet.py \
  --workbook 経費精算.xlsx --rows rows2.json
```

`--out` を付けると別ファイルに出力できる。保存後に openpyxl で開き直して検証しており、
既存シート・埋め込み画像・セルコメントはそのまま保たれる。

### 5. 受け渡し

Googleドライブのコネクタは既存ファイルの中身を差し替えられない（`update_file` は
名前と場所だけ）。したがって:

1. `SendUserFile` で更新版の xlsx をユーザーに渡す。
2. あわせて `mcp__Google_Drive__create_file`（`contentMimeType`
   `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`、
   `disableConversionToGoogleType: true`、`parentId` はマイドライブ = `root`）で
   `経費精算_更新YYYYMMDD.xlsx` としてアップロードする。
   元の `経費精算.xlsx` は消さず、差し替えるかどうかはユーザーに判断してもらう。

最後に、追加したシート名・件数・合計金額と、判読が怪しかった箇所を報告する。
