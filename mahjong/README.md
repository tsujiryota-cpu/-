# 🀄 麻雀カメラ参謀

麻雀ゲームの画面にスマホのカメラを向けると、手牌・河を読み取って

- **何を切るか**(向聴数と受け入れ枚数による牌効率。映像上の切る牌に赤枠と▼を表示)
- **鳴き判断**(ポン/チーできる牌ごとに「鳴く/微妙/スルー」と理由を表示。相手が切った直後はその牌への判定を大きく表示)
- **危険牌**(警戒する相手を指定すると、現物・筋・壁・字牌の枚数から危険度を表示。手が遠ければオリを提案)

をその場で表示する Web アプリです。認識はすべて端末内(WASM)で動き、映像はどこにも送信しません。

## 使い方(PC: 画面共有モード)

カメラを使わず、ゲーム画面を直接読み取るモードです。Chrome / Edge(PC版)で使えます。

1. PCのブラウザで麻雀ゲームを開く(別タブか別ウィンドウ)
2. このアプリを開き「ゲーム画面を共有して開始(PC)」を押して、ゲームのタブ(またはウィンドウ)を選ぶ
3. 判定パネルが常に手前に表示される小窓(Document Picture-in-Picture)で開くので、ゲーム画面の横や上に置く

スマホ(iPhone / Android)のブラウザは他アプリの画面を取り込めないため、スマホではカメラモードのみです。

## 使い方(スマホ1台: スクショ貼り付け)

1. ゲーム中にスクリーンショットを撮り、左下のサムネイルを長押し(または開いて共有)して「コピー」
2. このアプリに切り替えて「スクショを貼り付けて判定」(2回目以降は「📋 貼り付け」)を押す
3. 判定を見たらゲームに戻る

iPhone の「ショートカット」で「スクリーンショットを撮る → クリップボードにコピー → URL を開く(このアプリ)」を作り、
設定 → アクセシビリティ → タッチ → 背面タップ に割り当てると、背面を2回叩くだけでスクショ〜アプリ起動まで自動になります。
(`#img=<base64 JPEG>` を URL の末尾に付けて開くと、貼り付け操作なしでその画像を判定します)

## 使い方(スマホ: カメラモード)

1. `mahjong/index.html` を HTTPS で開く(GitHub Pages など。カメラ利用に HTTPS が必要)
2. 「カメラを開始」を押し、**スマホを横向き**にしてゲーム画面全体が映るように構える
3. 自分の番(手牌 14 枚など 3n+2 枚)では打牌候補、相手の番(3n+1 枚)では鳴き判断と待ちを表示
4. 相手がリーチしたら「上家 / 対面 / 下家」ボタンを押すと、その相手に対する危険度が出る
5. 場風・自風ボタンは鳴き判断の役牌判定に使う。🔇 を押すと切る牌を音声で読み上げ
6. 「スクリーンショット/動画で試す」でカメラ無しでも動作確認できる

## 仕組み

| ファイル | 役割 |
|---|---|
| `index.html` | 画面とメインループ(カメラ → 認識 → 判定 → 描画) |
| `vision.js` | 牌の認識。検出モデル(牌の位置) → 切り出し → 分類モデル(34種+非牌)。位置関係から手牌/各家の河/その他を判定 |
| `engine.js` | 麻雀ロジック。向聴数(一般形・七対子・国士)、受け入れ、打牌候補、鳴き判断、危険度 |
| `models/det.onnx`, `models/cls.onnx` | 自前で学習した小型モデル(合計約 4MB) |
| `ort/` | onnxruntime-web (MIT) の WASM ランタイム |
| `tiles/` | 表示用の牌画像。[FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles) (CC0) |
| `sw.js` | WASM のマルチスレッド実行を有効にする Service Worker |
| `train/` | 学習用スクリプト(合成データ生成・学習・ONNX 書き出し・ロジックのテスト) |

速度の目安: 検出 約0.1秒 + 分類 数十ms(PC の Chromium で計測)。河の牌は約1秒キャッシュして再分類を間引き、手牌は毎フレーム読み直します。

## 制限・注意

- 認識モデルは主に**合成画像**で学習しています(オープンな牌画像をゲーム画面風に並べ、カメラ撮影風の歪み・ぼけ・モアレを加えたもの)。雀魂については実際のプレイ画面1枚を素材と検証に使って調整済みですが、それ以外のゲームや牌デザインでは誤認識があり得ます。読み取った手牌は画面に常に表示されるので、おかしい場合は距離・角度・映り込みを調整してください。
- 河の持ち主(誰の捨て牌か)は「卓の中心を囲む風車状の配置」を仮定した位置関係で判定しています。映像上の枠の色で判定結果を確認できます。
- ドラ表示牌は卓の左上から自動検出します(「変更」ボタンで手動指定も可)。リーチの有無、点数状況、巡目は自動では読み取りません。危険度は「警戒する相手」を手で指定したときだけ計算します。
- 鳴き判断の「役の目安」は簡易判定です(役牌・タンヤオ・染め手・対々和)。
- 赤五は通常の五として扱います。
- オンライン対戦での利用可否は各ゲームの利用規約を確認してください。

## 再学習

```sh
pip install torch onnx onnxruntime opencv-python-headless cairosvg pillow
git clone https://github.com/FluffyStuff/riichi-mahjong-tiles   # TILE_DIR で Regular/ を指定
cd mahjong/train
TILE_DIR=.../Regular/ python3 gen.py data/train 6000 0        # 合成データ
TILE_DIR=.../Regular/ python3 gen.py data/val 200 500000
python3 train_det.py data det.pt 50                            # 検出モデル (分)
python3 train_cls.py data cls.pt 30                            # 分類モデル (分)
python3 export.py det.pt cls.pt ../models
node test_engine.js                                            # 麻雀ロジックのテスト
```

`MULTI=1` と `ALT_TILE_DIR` を指定すると、別の絵柄・フォント描画の牌も混ぜて生成します。
